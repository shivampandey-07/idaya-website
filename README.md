# IDAYA Delhi

Static boutique catalogue and enquiry website.

## Files
- `index.html`: landing page, catalogue and enquiry dialog
- `style.css`: responsive design
- `app.js`: filters, enquiry copy and silent video playback
- `assets/`: local video, poster and reference photographs

No build, package installation, API key or backend is required. Serve this folder using any static web server. All paths are relative, including for GitHub Pages subdirectories.

The hero film was supplied for this project. Catalogue photography is illustrative, with source credits on the page; replace it with approved IDAYA product images before presenting it as actual stock. Prices, orders and payments are not implemented. Enquiries are copied by the visitor and sent manually through Instagram. The page is marked noindex while it is a preview.
