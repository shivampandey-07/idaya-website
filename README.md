# IDAYA Delhi

Static boutique catalogue and enquiry website.

## Files
- `index.html`: landing page, catalogue and enquiry dialog
- `style.css`: responsive design
- `app.js`: enquiry copy, silent video playback and deferred Instagram embeds
- `assets/`: local video, poster, lotus mark and wordmark

No build, package installation, API key or backend is required. Serve this folder using any static web server. All paths are relative, including for GitHub Pages subdirectories.

The hero film was supplied for this project. Every look in the collection is an official Instagram embed of a post from [@idaya_delhi](https://www.instagram.com/idaya_delhi/), so all fashion imagery on the page is IDAYA's own and no third-party photography is hosted here. Prices, orders and payments are not implemented. Enquiries are copied by the visitor and sent manually through Instagram. The page is marked noindex while it is a preview.
